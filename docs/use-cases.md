## Дополнения из архитектуры

| Возможность | Реализация |
| --- | --- |
| ИИ-помощник | Ограниченные tool calls через API; локальный резервный режим |
| Общие параметры чата и формы | selection_requests, revision, HTTP 409 |
| Контекст диалога | Сохранённые сообщения и текущий черновик |
| Сравнение | Таблица 2–3 профилей текущей тройки |
| Альтернативы | Реальные повторные проверки при изменении одного поля |
| История | Снимки последних 20 запусков текущего запроса |
| Происхождение данных | synthetic, city_imputed, price_imputed в профиле и карточках |
| Администрирование | CLI validate / prepare / features / inspect-run / benchmark |
| Воспроизводимый запуск | start.cmd / start.ps1, Dockerfile, Compose, npm lockfile |
| Работа при сбоях | Таймауты, явный локальный режим чата, отдельные технические ошибки |

## Границы и проверки окружения

- Нейросетевой смысловой поиск активируется отдельно. Режим по умолчанию — словарь признаков и текстовое сходство; это не embedding-модель.
- API LLM и embedding-режимы имеют программную интеграцию, но реальные внешние вызовы требуют ключа/скачивания весов и не проверены без них.
- PostgreSQL настроен в Docker Compose; локальные проверки проведены на SQLite, поскольку Docker Engine не запущен.
- Профили и календари хранятся вместе в JSON; отдельные редактируемые сущности календарей/признаков не нужны для фиксированного каталога из 66 записей.
- Бронирование, сообщения подрядчикам, оплата, аккаунты и общий кабинет мероприятий не входят в реализованный сценарий.

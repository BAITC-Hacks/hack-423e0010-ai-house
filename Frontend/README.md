# AI House — Frontend

Стартовый проект на React, TypeScript и Vite. Для проверки запуска оставлена демонстрационная страница Vite.

## Запуск

Проверено на Node.js 22.19.0 и npm 10.9.3.

Из корня репозитория:

```bash
cd Frontend
npm ci
npm run dev
```

Откройте адрес, который Vite напечатает в терминале (обычно http://localhost:5173).

## Команды

- `npm run dev` — сервер разработки с автоматическим обновлением страницы.
- `npm run build` — проверка TypeScript и сборка в `dist/`.
- `npm run lint` — проверка кода с помощью Oxlint.
- `npm run preview` — локальный просмотр готовой сборки после `npm run build`.

## Структура

- `src/App.tsx` — начальный компонент приложения.
- `src/App.css` — стили компонента.
- `src/index.css` — глобальные стили.
- `src/main.tsx` — точка входа React.
- `public/` — статические файлы.
- `vite.config.ts` — конфигурация Vite.

Зависимости и результаты сборки исключены из Git через `.gitignore`. Файл `package-lock.json` нужно коммитить вместе с исходниками для воспроизводимой установки зависимостей.

# Tandau — Frontend

Адаптивный MVP для подбора event-подрядчиков в Казахстане на React, TypeScript и Vite. Форма собирает один JSON-запрос; интерфейс показывает до трёх карточек с объяснениями, основаниями выбора и полными профилями.

## Запуск

Node.js 22.12+ (проверено на 22.19.0) и npm.

```bash
cd Frontend
npm ci
npm run dev
```

Откройте адрес из терминала, обычно http://localhost:5173.

```bash
npm run build       # Проверка TypeScript и production-сборка
npm run preview     # Просмотр сборки
npm run lint        # Oxlint
npm test            # Проверка сценариев и API-адаптера
npm run format      # Prettier
```

## Что реализовано

- Город, дата, формат, категория, бюджет на одного подрядчика; необязательные язык, длительность и пожелания.
- До трёх результатов с ценой «от», объяснением, раскрываемыми основаниями и полным описанием профиля.
- Разные состояния `MATCHED`, `CATEGORY_ABSENT`, `NO_MATCH`; загрузка, валидация и технические ошибки отображаются отдельно.
- Календарь для всех категорий, в том числе площадок; проверка формата, бюджета, языка и длительности.
- Детерминированный локальный подбор: совпадения ключевых слов, затем цена, затем ID. Это демонстрация поведения интерфейса, **не семантический ИИ**.
- При пустом результате — вычисленные альтернативы. Они применяются только после нажатия пользователем.
- Избранное и параметры в localStorage; сравнение до трёх карточек одного запроса.
- Отметка устаревших результатов после изменения формы; отмена предыдущего запроса; таймаут API 10 секунд.
- Доступные с клавиатуры формы и модальные окна, адаптивность, поддержка reduced motion. Шрифты и иллюстрации локальные, внешних запросов в демо нет.

Помощник по пожеланиям помогает составить текст и перенести его в форму. Свободный диалог с LLM, смысловое ранжирование, бронирование, авторизация и сообщения подрядчикам не реализованы.

## Данные

`src/data/catalog.json` импортирован из предоставленного файла `hackathon dataset anonymized .csv`: 66 профилей, 17 категорий, города Алматы, Астана и исходная метка «Зарубежье». Сохранены полные описания, несколько категорий у профиля, занятые даты, языки, форматы, цены и признаки происхождения.

13 профилей синтетические; у 18 цена и у 8 город дополнены при подготовке исходного датасета. Эти признаки видны в интерфейсе. Имена анонимизированы. Изображения — декоративные иллюстрации, а не фотографии подрядчиков.

Календарь покрывает **23.09–31.12.2026**. Вне этого окна форма не подтверждает доступность. `max_hours: null` означает, что длительность неприменима к услуге. Структурированные поля имеют приоритет над текстом описания. Цена «от» не гарантирует окончательную смету.

Для повторного импорта:

```bash
python3 scripts/import_catalog.py '/полный/путь/к/каталогу.csv'
```

Скрипт использует стандартную библиотеку Python. Новые города, категории или диапазон календаря нужно также согласовать в `src/domain/selection.ts`. Версию каталога после обновления измените в `src/services/demo.ts`.

## Подключение backend

1. Скопируйте `.env.example` в `.env.local`.
2. Укажите URL endpoint:

   ```dotenv
   VITE_RECOMMENDATIONS_URL=http://localhost:8000/api/recommendations
   ```

3. Перезапустите Vite (для production — выполните новую сборку).
4. Endpoint должен принимать `POST application/json` и возвращать описанный ниже контракт. Если backend на другом origin, разрешите origin фронтенда и `Content-Type` в CORS.

При пустом URL работает локальный каталог. При заданном URL используется **только backend**, без скрытого переключения на демо при ошибках. API-ключи в `VITE_*` не размещаются: переменные Vite публичны.

Документация: [контракт API](docs/api-contract.md), [JSON Schema запроса](docs/request.schema.json), [JSON Schema ответа](docs/response.schema.json). Типы, runtime-валидация и справочники находятся в `src/domain/selection.ts`; сетевой адаптер — в `src/services/api.ts`.

## Проверки

Автотесты покрывают сценарии UC-01–UC-12: фильтрацию, изменение даты, редкую категорию, два вида пустой выдачи, воспроизводимость порядка, проверяемые основания, ограничения календаря, площадки и неприменимую длительность. API-тесты проверяют один POST, точный JSON, некорректный ответ, сетевые ошибки, отмену и таймаут.

Браузерная проверка включает UC-13 (полный профиль), избранное после перезагрузки, сравнение, альтернативы, изменение пожеланий и ширины 320, 390, 768, 1024 и 1440 px.

## Структура

```text
src/
  App.tsx                  Состояние страницы и пользовательские сценарии
  components/              Форма, выдача, профиль, модальное окно, иллюстрации
  domain/selection.ts      Типы, справочники и Zod-схемы
  data/catalog.json        Импортированный анонимизированный каталог
  services/api.ts          Один POST endpoint, таймаут и проверка ответа
  services/demo.ts         Локальная демонстрационная фильтрация
scripts/import_catalog.py  Воспроизводимый импорт CSV
tests/                     Сценарии каталога и API-адаптера
docs/                      Контракт для backend-команды
```
